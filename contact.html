Frequently Asked Questions

Quick answers to common questions about using Moleqyn in schools.

Is Moleqyn free for schools and students? +
Yes! Moleqyn is an open educational chemistry simulator suite built for Class 6–12 CBSE, ICSE, and State Board curriculums. All simulators, quizzes, and resources are 100% free to access without subscription walls.
Does it work on low-spec computer lab PCs without high-end GPUs? +
Absolutely. Moleqyn is built using lightweight HTML5 Canvas 2D and pure JavaScript without heavy 3D rendering engines like WebGL or Unity. It runs smoothly at 60 FPS even on dual-core school PCs and mobile browsers.
Can teachers use this during Smart Board live classroom teaching? +
Yes, each virtual simulator features touch-friendly controls, high-contrast dark/light modes, and a fullscreen shortcut (F key) optimized specifically for interactive classroom projectors and digital smart boards.
Are student progress and quiz results saved securely? +
All student activity, XP, completed labs, and quiz mastery records are saved locally in the browser via HTML5 localStorage. No sensitive personal data or passwords are transmitted to third-party ad networks.
