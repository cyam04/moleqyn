Official IUPAC Priority Order of Functional Groups

When a polyfunctional organic compound has two or more groups, the higher priority group acts as the principal functional group (suffix), while lower priority groups are named as substituents (prefixes).

Class 12 Coordination Compounds Nomenclature

Master Werner's nomenclature rules: Ligands in alphabetical order with prefixes (di, tri, tetra), central metal name, and Roman numeral oxidation state.

[Co(NH₃)₆]Cl₃
Hexaamminecobalt(III) chloride
Rules Applied: Cationic coordination sphere named first. Neutral ligand NH₃ named 'ammine'. Cobalt oxidation state = +3. Counter anion chloride named last.
K₄[Fe(CN)₆]
Potassium hexacyanidoferrate(II)
Rules Applied: Potassium cation named first. Anionic coordination entity requires '-ate' suffix on metal (ferrate). CN⁻ is named 'cyanido'. Fe state = +2.
[Pt(NH₃)₂Cl(NO₂)]
Diamminechloridonitrito-N-platinum(II)
Rules Applied: Alphabetical order of ligands: Ammine > Chlorido > Nitrito. Linkage through nitrogen denoted as nitrito-N. Neutral complex retains metal name.
[Ni(CO)₄]
Tetracarbonylnickel(0)
Rules Applied: CO ligand named 'carbonyl'. Nickel has 0 oxidation state indicated as (0) in parentheses.
[Cr(H₂O)₄Cl₂]⁺
Tetraaquadichloridochromium(III) ion
Rules Applied: Water ligand is 'aqua'. Alphabetical: aqua before chlorido. Cr oxidation state = +3. Ends in 'ion'.
K₂[PdCl₄]
Potassium tetrachloridopalladate(II)
Rules Applied: Anionic complex converts Palladium to 'palladate'. Oxidation state = 4 - 2 = +2.
